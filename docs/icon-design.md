# 卡皮巴拉视觉

![卡皮巴拉状态栏图标预览](assets/capybara-status-icon-preview.png)

## 状态栏图标

- 面向 macOS 16–18pt 状态栏尺寸，以侧身全身轮廓表达卡皮巴拉：楔形长头、钝鼻、低矮桶状身体、无尾和短腿。
- 一只眼睛是中间略高的短弧，形成有笑意的眯眼表情；不使用缩小后易糊的瞳孔、高光或毛发。
- 采用系统模板图标机制，只保留轮廓与关键黑点，由 macOS 自动适配深色、浅色和选中状态。
- 不加入颜色或文字，避免缩小后模糊成块。

源图由 `CapybaraStatusIcon.swift` 使用 AppKit 贝塞尔路径绘制，可确定性修改和复现。

## 窗口 Logo

![眯眼像素卡皮巴拉](assets/capybara-pixel-logo.png)

窗口标题区使用 96×64 px 透明 PNG，以 42×28pt 显示。它使用完整侧身轮廓和笑弧眯眼，暖棕色像素块提供产品识别；位置在“待办”标题左侧，不占用列表内容空间。
